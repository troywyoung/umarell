# Document staging review workflow

Document how the team will use staging together before releasing to production.

Describe how changes get reviewed in staging, who validates them, what kinds of checks happen there, and when a build is ready to promote to production. Keep the workflow lightweight and repeatable.

## Task Type

implement

## Blocked By

- [Set Up Production Deployment Flow](set-up-production-deployment-flow.md)


## Definition of Done

- The staging review workflow is documented in a fact artifact
- The criteria for promoting a change to production are written down
- The workflow explains how collaborators access and review staging
- The workflow is short enough to follow consistently
