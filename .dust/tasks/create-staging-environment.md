# Create staging environment

Create a working staging environment that mirrors production closely enough for collaborative review.

Set up the staging app, configure environment variables, connect the deployment target, and make the environment reachable by the team. The setup should support repeated deploys without manual rebuild steps.

## Task Type

implement

## Blocked By

(none)


## Definition of Done

- A staging environment exists and can be deployed to repeatedly
- Environment variables and secrets are configured for staging
- The team has a stable URL or access path for staging
- A deploy to staging can be triggered using the documented workflow
