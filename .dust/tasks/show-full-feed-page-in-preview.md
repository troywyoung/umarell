# Show full feed page in preview

Make the design preview render the feed page instead of a single-card comparison view. Replace the confusing before-and-after framing with a clearer draft preview that shows multiple observations in page context.

## Task Type

implement

## Blocked By

(none)


## Definition of Done

- Preview renders a feed-like page with multiple observations instead of only the first observation card.
- Preview includes surrounding page context so the feed feels like the actual page, not an isolated component.
- The before-and-after comparison mode is removed or hidden from the preview flow.
- Preview behavior is understandable without requiring explanation of production-versus-draft modes.
